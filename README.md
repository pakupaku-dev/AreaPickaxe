# AreaPickaxe

Paper 26.2用の3x3・5x5範囲採掘つるはしプラグインです。

## 種類

次の素材それぞれに3x3版と5x5版があります（合計6種類）。

- 鉄のつるはし
- ダイヤモンドのつるはし
- ネザライトのつるはし

プレイヤーが向いている面に沿って範囲採掘します。スニークしながら掘ると、
通常どおり1ブロックだけ採掘できます。

壁の下側を狙った場合、採掘範囲は床下へ伸びないよう上側へ自動調整されます。
また、範囲内にプレイヤーを支えている足元のブロックが入っても、そのブロックは
巻き込み破壊されません。足元のブロック自体を直接狙った場合は採掘できます。

## コマンド

素材には `iron`、`diamond`、`netherite` を指定します。

- `/areapickaxe give <3|5> <素材> [個数]`
- `/areapickaxe give <プレイヤー> <3|5> <素材> [個数]`
- `/areapickaxe apply <3|5>` - 手持ちの鉄・ダイヤ・ネザライトつるはしに付与
- `/areapickaxe reload`

短縮コマンドとして `/ap` も使用できます。

## 採掘処理

追加ブロックもPaperの通常プレイヤー採掘として処理します。そのため、耐久値、
耐久力、幸運、シルクタッチ、ドロップ、経験値、およびBlockBreakEventを利用する
保護プラグインが反映されます。初期設定では、つるはしの素材では正しく採掘できない
ブロックを範囲採掘の対象外にします。

設定は `plugins/AreaPickaxe/config.yml` で変更できます。


## ビルド

JDK 25とMaven 3.9以降を用意し、リポジトリ直下で `mvn clean verify` を実行します。
生成物: `target/AreaPickaxe-1.0.0.jar`。Paper 26.2の `plugins` フォルダーへ配置して再起動してください。
